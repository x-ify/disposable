## Before you start

An AI coding tool and fictional meeting notes. Any resulting app should process text locally.

## Quick start

1. Describe your own notes format with a fictional example.
2. Use the recipe to create a deterministic formatter.
3. Check every owner, date and task before sharing.

## Rebuild

Build a small local text-to-checklist formatter for my repeated meeting-note format. Ask for a fictional example first. Let me explicitly mark task, owner and due date using labeled lines; do not infer unstated facts or make network/model calls. Output a Markdown checklist preserving the original wording. Mark absent owners or dates as "to confirm". Include a preview and copy button; never overwrite input. Keep the text in memory and clear it on refresh. Test empty notes, repeated tasks, punctuation, non-English names and missing dates. Offer an editable format mapping instead of guessing.

## Limits

It formats explicitly labeled notes; it does not understand arbitrary meetings or invent missing assignments.
