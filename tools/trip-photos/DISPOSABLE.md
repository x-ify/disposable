## Before you start

An AI coding tool and a copy of a small photo folder. You will run the resulting tool on your own device.

## Quick start

1. Copy the recipe into your AI coding tool.
2. Build and test with five copied files.
3. Review the proposed names before applying them to a larger copied folder.

## Rebuild

Create a small local photo-renaming utility for a single trip. Let me choose an input folder, an output folder and a trip prefix. Sort files by their existing filename, show old and new names in a preview, and copy files into the output folder only after confirmation. Keep extensions and file contents unchanged. Never modify originals or overwrite an existing file. Number from 001. Include a dry-run mode, clear collision handling and a small test with five sample files. Do not read photo locations or upload files. Ask me which operating system I use before choosing an implementation.

## Limits

This is a creation recipe, not an installed program. Filename order may differ from capture time. Back up photos and inspect the output before using it.
